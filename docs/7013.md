# 7013 split-address 推論メモ

## 1. 対象
- 証券コード: 7013
- 企業名: IHI
- 対象行: 有報「主要な設備の状況（提出会社）」の `本社 (東京都江東区他)` 行
- 更新日: 2026-03-14

## 2. 観測事実（なぜおかしいか）
- 有報の `本社` 行は所在地が **「東京都江東区他」** となっており、単一地点の土地ではなく **複数所在地の合算** を含む。
- 同行の土地面積は `129,926 (千㎡)` → `129,926,000 m2` と極端に大きい。
- パイプラインでは Web 住所補完により `東京都江東区豊洲3丁目1番1号`（本社住所）へ寄せて街区解決され、
  この巨大面積に都心部の単価が掛かって **推定土地時価・含み益・時価総額比が異常に跳ねる**。

## 3. 分割方針
- `本社` 行は合算行として扱い、東京都分だけを小さく切り出し、残余は `全国各所` に回して **東京都評価の対象外** にする。
- 東京都分の面積は、近傍の公示地価標準地（公示点 `13108-005-017`、所在地 `東京都江東区豊洲3丁目1番54`）の
  **地積 `16,242 m2 (L01_027)`** を proxy として採用する。
- 全国残余面積は差分で算出する。
  - `129,926,000 - 16,242 = 129,909,758 m2`

## 4. パッチ反映値
```yaml
'7013':
  本社:
  - name: 本社(豊洲)
    address: 東京都江東区豊洲3丁目1番1号
    area_m2: 16242.0
    area_m2_is_estimated: true
    area_m2_source: 公示地価標準地(豊洲3丁目近傍)の地積(L01_027)による推定
    area_m2_source_url: https://www.reinfolib.mlit.go.jp/
    area_m2_note: 公示点 13108-005-017 (東京都江東区豊洲3丁目1番54) の地積 16,242m2 を代理値として採用
  - name: 本社(全国各所・合算)
    address: 全国各所
    area_m2: 129909758.0
    area_m2_is_estimated: true
    area_m2_source: 有報(本社行の所在地が「東京都江東区他」)の合算面積から東京推定面積を控除
    area_m2_source_url: https://disclosure2dl.edinet-fsa.go.jp/searchdocument/pdf/S100W1K1.pdf
    area_m2_note: 129,926,000 - 16,242 = 129,909,758m2
```

## 5. 注意
- proxy 面積は公示地価標準地の「地積」であり、本社敷地そのものの登記面積ではない。
- 精密化する場合は、固定資産内訳注記・登記情報・不動産開示資料などで本社敷地面積を取得して上書きする。
