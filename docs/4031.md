## 3. 問題の詳細

有報「設備の状況」の「本社(東京都千代田区)」行は以下を含む複合エントリ:
- セグメント: 肥料事業 / 化学品事業 / **不動産事業** / その他事業 / 全社
- 設備内容: **管理・賃貸等不動産その他施設**
- 注記: 「上表には、賃貸中の建物及び土地が含まれております。また、上表のほか、当社本社事務所及び工場用土地を賃借しております。」

つまり:
1. **本社オフィスは賃借** (住友不動産九段ビル15階) → 自社土地なし
2. 157,000 m2 の大部分は **不動産事業の賃貸用土地** (旧支店工場跡地の有効活用等)
3. 簿価 ¥1,180M / 157,000 m2 = **平均 ¥7,516/m2** → 都心ではあり得ない単価 (全国散在を示唆)
4. 旧overrideの丸の内住所は完全に誤り (登記上の本店所在地は千代田区九段北1-8-10)
