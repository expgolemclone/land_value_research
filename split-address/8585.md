## 4. 推論

有報の `東京都千代田区他 22,000㎡` は、所在地自体が合算表示である。したがって、CSV の `東京都千代田区丸の内1丁目3番3号` に 22,000㎡ を丸ごと載せた現状は BAD_PATTERN_1 に該当する。

東京側の拠点は、公式サイトで確認できる現行本社所在地 `東京都千代田区麹町5丁目2番地1` を採用する。麹町5-2-1 の K-WINGビルは JLL 掲載で地上11階建て・基準階97㎡の小規模オフィスであり、都心本社単独で 22,000㎡ を持つ形とは整合しない。したがって、東京側は保守的に 97㎡ を proxy とする。

一方で、グループ会社公式ページおよびオリコの公表資料から、`オリコ本社別館` が埼玉県ふじみ野市西鶴ヶ岡1丁目4番1号に存在することを確認できる。`東京都千代田区他` の `他` は、こうした非都心の本社別館等を含む合算資産とみるのが自然である。

## 5. 推論式

`22,000.00 - 97.00 = 21,903.00 (m2)`

## 6. 最終配分

- 本社部門(麹町本社): 東京都千代田区麹町5丁目2番地1, 97.0 m2
- 本社部門(本社別館等・合算): 全国各所, 21,903.0 m2

- `config/address_patches/8585.yaml` では、出力CSVの `本社部門` を list 形式に分割する。
- 東京評価に使う住所は `東京都千代田区麹町5丁目2番地1` に補正する。
- 残余 21,903㎡ は、`東京都千代田区他` の `他` に対応する非都心資産として `全国各所` に切り出す。
