# 5269 split-address 推論メモ

## 1. 対象

- 証券コード: 5269
- 企業名: 日本コンクリート工業株式会社
- 対象事業所: 本社・工場
- 更新日: 2026-03-21

## 2. 元データ

- 元の土地面積: 33,000 m2
- 元住所: 東京都港区
- 問題点: 都心大面積かつ、NC日混工業株式会社の公式会社概要では芝浦本社のほかに工場として結城工場・鈴鹿工場のみが開示されている。東京都港区芝浦4丁目6番14号は親会社の日本コンクリート工業株式会社の本社所在地とも一致するため、`本社・工場 (東京都港区)` は会計上のラベルであり、33,000m2 全量を港区に置くのは不適切と判断した。

## 4. 判定

- `本社・工場 33,000m2 @ 東京都港区` は、芝浦本社テナント/登記上所在地と、東京外の工場資産をまとめた表示とみるのが自然。
- 33,000m2 を港区地価で評価すると過大。東京保有地として扱わず、東京外工場資産の合算に振り替える。
- 公式開示だけでは結城工場・鈴鹿工場への個別面積配分までは確定できなかったため、今回は `結城工場・鈴鹿工場(東京外合算)` として 33,000m2 を保持した。
