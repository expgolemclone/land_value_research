# 5201 split-address 推論メモ

## 1. 対象

- 証券コード: 5201
- 企業名: AGC株式会社
- 対象事業所: 本社
- 更新日: 2026-03-17

## 2. 元データ

- 元の土地面積: 409,000.0 m2
- 元住所: 東京都千代田区丸の内1丁目4番53
- 問題点: 出力CSVの住所が有報上の本店所在地と一致しないうえ、有報注記に「本社には、関係会社に賃貸している土地等を含んでおります。」とあり、丸の内本社以外の土地が合算されている。

## 3. 判定

- 判定: 過大評価の疑いあり
- 理由: 丸の内の単独地点に 409,000m2 をぶら下げるのは立地・面積の両面で不自然。有報注記により、本社行には関係会社向け賃貸土地等が混在していることが明示されている。
- 対応: `本社` を `本社(丸の内)` と `本社(関係会社賃貸土地等・合算)` に分割する。

## 5. 推論式

- 丸の内本社の住所は有報ベースで `東京都千代田区丸の内1丁目5番1号` を採用。
- AGC公式アクセスページが本社受付を新丸の内ビル30階に置いているため、丸の内本社の土地持分は少なくとも「1フロア相当のオフィス持分」を上限寄りの保守値として代理採用する。
- 推定式: `9,997.44 x 3,727.01 / 195,685.43 = 190.410491...`
- 採用値:
  - 本社(丸の内): 190.4m2
  - 本社(関係会社賃貸土地等・合算): `409,000.0 - 190.4 = 408,809.6m2`
