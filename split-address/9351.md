## 4. 判断

### 本社

- 公式に番地まで確認できる本社所在地は `東京都中央区晴海1丁目8番8号` のみ。
- 有報では大井事業所が独立行で、しかも借地扱いなので、本社の `中央区他` を大井へ読み替えることはできない。
- 同じ有報の固定資産明細には `土地 本社賃貸用地 324百万円` の減少注記があり、本社関連土地に本社所在地以外の資産が含まれていた可能性は高い。
- ただし、その賃貸用地の所在地・地積は公開ソースだけでは特定できず、2025年3月31日時点の本社 18,146㎡ を番地レベルへ再配分する根拠が不足する。
- よって本社は代表住所 `東京都中央区晴海1丁目8番8号` を維持し、`他` の内訳は未解明として扱う。

### 東京支店

- 公式拠点紹介で、東京支店のうち番地まで確定できる自社拠点は少なくとも以下の2件。
  - `有明営業所(第一倉庫)` : 東京都江東区有明4丁目4番21号
  - `有明営業所(第二倉庫)` : 東京都江東区有明4丁目3番22号
- 大井事業所は別行・別拠点なので、東京支店 26,847㎡ の配分対象から除外してよい。
- 東京支店ページには有明第1・第2倉庫の設備面積が `14,128㎡` と `9,119㎡` で出ているため、公開データだけで番地レベル配分を作るならこの2拠点へ按分するのが最も defensible。
- 推定式:
  - 第1倉庫 = 26,847 × 14,128 / (14,128 + 9,119) = 16,315.84...
  - 第2倉庫 = 26,847 × 9,119 / (14,128 + 9,119) = 10,531.15...
- 四捨五入後の最終配分:
  - 有明営業所(第一倉庫): 16,316㎡
  - 有明営業所(第二倉庫): 10,531㎡
- これは登記簿ベースではなく、公式サイト掲載の倉庫面積比による推定値。
