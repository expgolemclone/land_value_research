# 7042 split-address 調査メモ

## 1. 対象

- 証券コード: 7042
- 企業名: 株式会社アクセスグループ・ホールディングス
- 更新日: 2026-03-17

## 2. 結論

- `本社` `渋谷オフィス` `世田谷オフィス` はいずれも合算住所ではなく、公式サイト記載の番地と `data/output/7042_output.csv` が一致した。
- この銘柄の時価総額比が異常に高い主因は、住所の合算ではなく、有報「設備の状況」注記2の **賃借設備** を土地として取り込んでいる点にある。
- さらに `年間賃借料(千円)` を `土地簿価(円)` に誤変換している疑いが強い。例えば本社の `21,805` が `21,805,000,000円` として入っており、千円を円へ直すなら `21,805,000円` が自然で、現値は 1000 倍過大。

## 3. 元データ照合

### 有報注記2

2025年3月31日現在の有報「主要な設備の状況」注記2には、以下が「連結会社以外から賃借している設備」として並ぶ。

| 事業所名 | 有報の設備内容 | 床面積(㎡) | 年間賃借料(千円) |
| ---- | ---- | ----: | ----: |
| 本社 | 事務所 | 202.25 | 21,805 |
| 渋谷オフィス | 事務所 / フォーラム施設 / 情報通信機器等 | 1,659.95 | 99,448 |
| 世田谷オフィス | 事務所 / 情報通信機器等 | 583.35 | 15,600 |

### 出力CSVとの一致

`data/output/7042_output.csv` では、上記 3 件の `土地面積(m2)` がそれぞれ `202.25 / 1659.95 / 583.35` となっており、有報の **床面積** と完全一致する。

また `土地簿価(円)` は `21,805,000,000 / 99,448,000,000 / 15,600,000,000` で、有報の **年間賃借料(千円)** を不自然に土地簿価へ転記した形になっている。

## 5. 判定

- BAD_PATTERN_1 のような「本社他」「及び」型の合算ではない。
- 住所分割で時価総額比異常は解消しない。
- 修正優先度は住所パッチではなく、賃借設備注記を土地データへ流し込まないこと、および `年間賃借料(千円)` を `土地簿価(円)` として扱わないことにある。
