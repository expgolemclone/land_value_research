# 7042 split-address 推論メモ

- 証券コード: 7042
- 企業名: 株式会社アクセスグループ・ホールディングス
- 対象事業所: 本社 / 渋谷オフィス / 世田谷オフィス
- 更新日: 2026-03-19

## 2. パイプライン出力

| 事業所名       | 住所                                 | 土地面積(m2) | 土地簿価(円)    | 推定時価(億円) |
| -------------- | ------------------------------------ | ------------ | --------------- | -------------- |

## 3. 判定: 含み益は存在しない（誤抽出）

**この銘柄の土地含み益はゼロ。ratio=7.577は完全な誤り。**

### 根拠: 有報に土地の記載がない

有報「主要な設備の状況」(1)提出会社の設備表を確認すると：

```
事業所名         帳簿価額(千円)
(所在地)         建物    工具器具備品  ソフトウエア  合計
本社(東京都港区)   −        −           −           −
渋谷オフィス       1,349    504          −           1,854
```

**土地の列自体が存在しない。** この会社は土地を一切保有していない。

### 誤抽出の仕組み

有報の注記2に「連結会社以外から賃借している設備」として以下が記載されている：

| 事業所名              | 設備の内容               | 床面積(m2) | 年間賃借料(千円) |
| --------------------- | ------------------------ | ---------- | ---------------- |
| 本社(東京都港区)       | 事務所                   | 202.25     | 21,805           |
| 渋谷オフィス(渋谷区)  | 事務所/フォーラム施設等  | 1,659.95   | 99,448           |
| 世田谷オフィス(世田谷) | 事務所/情報通信機器等    | 583.35     | 15,600           |

パイプラインの抽出ロジックが、この**賃借設備テーブル**を**自社保有の土地テーブル**と誤認し：
- **床面積(m2)** → 土地面積(m2)
- **年間賃借料(千円)** → 土地簿価(円)（千円→円の単位変換も誤り、1000倍過大）

として取り込んだ結果、存在しない土地に174億円の時価がついている。

### 簿価の異常値で気づける

- 本社の「土地簿価」21,805,000,000円（218億円）— 南青山202m2の土地が218億円は異常
- 渋谷オフィスの「土地簿価」99,448,000,000円（994億円）— 渋谷1,660m2が994億円は異常
- 推定時価より簿価の方がはるかに大きい（評価倍率 0.13-0.14倍）— 通常ありえない

これらは年間賃借料を円単位で誤読した結果であり、実際の賃借料は：
- 本社: 21,805千円 = 2,180万円/年
- 渋谷: 99,448千円 = 9,945万円/年
- 世田谷: 15,600千円 = 1,560万円/年

いずれも都心賃貸オフィスの賃料として妥当な水準。

## 4. テナント判定

- **3拠点すべてテナント（土地非保有）**
- 有報の設備表(1)提出会社に土地列なし
- 有報注記2で「連結会社以外から賃借している設備」として明記
- 公式サイトでも各オフィスの住所はビル名付き（南青山ビル、渋谷クロスタワー等）で、自社ビルの記載なし

## 7. 本件の修正方針

### split-addressで対応可能な範囲

テナント判定を適用し、3拠点すべて area_m2=0.0 にすることで推定時価をゼロにできる。

### split-addressでは対応できない根本原因

抽出ロジック（`src/pdf_extract.py`）が有報の「賃借設備」注記テーブルを「自社保有の土地」テーブルと混同している。同様の誤抽出は 9213(セイファート)、2332(クエスト)、9788(ナック)、3690(イルグルム)、6093(エスクロー・エージェント・ジャパン)、6181(タメニー) でも発生している。

## 8. 結論

- **この銘柄に土地含み益は存在しない**
- ratio=7.577は賃借設備の誤抽出が原因
- 有報に土地保有の記載は一切なく、3拠点すべてが賃借オフィス
- パッチでテナント判定（area_m2=0.0）を適用することで是正可能
- 根本的には抽出ロジックの修正が必要（同様の誤抽出が少なくとも6件存在）
