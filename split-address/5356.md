# 5356 split-address 推論メモ

## 1. 対象

- 証券コード: 5356
- 企業名: 美濃窯業株式会社
- 対象事業所: 本社他、東京営業所及び海外事業部
- 更新日: 2026-04-05

## 2. 元データ

- 本社他: 東京都中央区他 / 1,074m2 / 土地簿価 4,940千円
- 東京営業所及び海外事業部: 東京都千代田区 / 483m2 / 土地簿価 240,058千円
- 問題点:
  - `本社他` は岩佐機械工業株式会社の「東京都中央区他」集約行で、公開情報から確認できる本社所在地は `東京都中央区東日本橋3-7-19 友泉東日本橋駅前ビル3F` のみ。
  - `東京営業所及び海外事業部` は出力CSVが `東京都千代田区丸の内1丁目4番1号` に誤紐付けされているが、公式サイトでは `東京都千代田区神田錦町3-16`。

## 3. 判断

- 東京営業所及び海外事業部:
  - 美濃窯業公式の「組織図・事業所一覧」で `東京営業所` と `海外事業部` はともに `東京都千代田区神田錦町3-16`。
  - 有報の主要設備表では同拠点に建物 538,495千円、土地 240,058千円、設備内容 `管理、販売及び賃貸設備` が計上されている。したがって、丸の内アドレスへの誤紐付けを修正し、土地 483m2 は当該拠点に残す。
- 本社他:
  - 美濃窯業公式の関連会社欄と岩佐機械工業公式サイトは、いずれも本社を `東京都中央区東日本橋3-7-19 友泉東日本橋駅前ビル3F` としている。
  - 友泉東日本橋駅前ビルは賃貸オフィスビルであり、岩佐機械工業は3F入居。公開情報上、東日本橋以外の具体的な保有地は確認できない。
  - 有報の土地簿価は 4,940千円で、中央区東日本橋の自社保有地 1,074m2 としては不自然。`他` に未特定保有地が含まれる合算行と判断し、東京本社は `0.0m2`、残り `1,074.0m2` は `全国各所` に退避する。
