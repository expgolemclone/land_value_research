## 4. 推論

1. 2025年3月期の有報キャッシュでは、関東事業部の土地面積48,731.33㎡は据え置きのまま、所在地だけが東京都港区へ変更されている。
2. 2024年3月期の公式アニュアルレポートでは、まったく同じ48,731.33㎡が神奈川県厚木市として計上されている。
3. 同社の主要事業所一覧では、東京都港区芝1丁目12番7号は関東事業部の管理拠点住所として確認できるが、都心の営業所住所に48,731.33㎡全量を載せるのは不自然である。
4. よって、2025年3月期は管理拠点住所の更新により、従前からの関東圏物流資産が東京住所へ代表付けされたと判断した。

## 5. 東京側面積の推定

- 対象住所: 東京都港区芝1丁目12番7号
- 推定方法: 近傍公示地価標準地3点の地積を逆距離加重平均
- 使用点:
  - 13103-005-003: 港区芝2-40-1, 499㎡, 距離190.941m
  - 13103-005-012: 港区芝大門2-11-1, 400㎡, 距離456.097m
  - 13103-005-034: 港区芝3-6-9, 247㎡, 距離515.701m
- 推論式: `(499/190.941 + 400/456.097 + 247/515.701) / (1/190.941 + 1/456.097 + 1/515.701)`
- 推定結果: 423.67㎡

## 6. 最終配分面積

- 関東事業部(東京営業所): 423.67㎡
- 関東事業部(全国各所・合算残余): 48,307.66㎡
- 検算: 423.67 + 48,307.66 = 48,731.33㎡

## 7. 判断

- patch では `関東事業部` を list 形式で分割し、東京営業所のみ東京都港区芝1丁目12番7号へ割当
- 残余は `全国各所` として退避し、東京都地価の過大評価から切り離す
