## 4. 判断

### 本店

- 中央区日本橋の本店所在地は公式会社概要で確認できる
- 同所在地の日本橋ダイヤビルディングは会社公式リリースで敷地面積 `5,265.97㎡`
- よって、有報 `104,000㎡` のうち中央区日本橋に残すのは `5,265.97㎡` とし、残余 `98,734.03㎡` は「ほか所在」の合算資産として切り離す

計算:

```text
104,000.00 - 5,265.97 = 98,734.03
```

### 東京支店

- 公式拠点ページで東京支店所在地は `東京都中央区新川1丁目28番24号`
- 同ページで、東京支店配下に `青海営業所(江東区青海4丁目7番6号)`、`有明営業所(江東区有明1丁目3番33号)`、`大井営業所(品川区八潮2丁目3番10号)`、`羽田営業所(大田区東海4丁目3番1号)` などの物流拠点を確認
- したがって、`153,000㎡` を中央区新川1丁目28番24号に全付けするのは不適切
- 新川側の中央区アドレスは、国交省2025年地価公示の近傍標準地 `13102-005-021` の地積 `458㎡` を proxy として採用
- 残余 `152,542㎡` は公式拠点ページで確認できる湾岸物流拠点群の代表住所として `青海営業所` に寄せる

計算:

```text
153,000.00 - 458.00 = 152,542.00
```
