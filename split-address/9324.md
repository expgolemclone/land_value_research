- 証券コード: 9324
- 企業名: 安田倉庫
- 対象事業所: 東京地区芝浦営業所
- 更新日: 2026-03-17

## 2. 元データ

- 元の土地面積: 52,000 m2
- 元住所: 東京都港区芝浦3丁目1番1号

## 4. 推論式

公開地積を確認できた東京物流拠点:

- 平和島営業所: 14,878.00 m2
- 東雲営業所: 3,286坪 x 3.305785 = 10,863.95 m2
- 東雲営業所辰巳倉庫: 5,202.90 m2

合計:

- 14,878.00 + 10,863.95 + 5,202.90 = 30,944.85 m2

有報の東京地区芝浦営業所との差分:

- 52,000.00 - 30,944.85 = 21,055.15 m2

## 5. 判定

- `東京地区芝浦営業所` は単一の `東京都港区芝浦3丁目1番1号` ではなく、少なくとも平和島・東雲・辰巳を含む東京地区複数拠点の合算と判断
- 残余 21,055.15 m2 は、公式拠点一覧に載る芝浦営業所、大井営業所、大井埠頭営業所、平和島第二倉庫、板橋営業所などに対応するとみられる
- ただし公開資料だけでは各残余拠点の地積を番地単位で配分できないため、今回は港区一点評価を避ける目的で `全国各所` に退避した
- `東京地区不動産事業部` は公開問い合わせページで本社同一住所が確認できるため、現時点では `東京都港区芝浦3丁目1番1号` を維持
