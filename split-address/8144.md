# 8144 split-address 調査メモ

## 1. 対象

- 証券コード: 8144
- 企業名: デンキョーグループ HD
- 対象事業所: 全社
- 更新日: 2026-03-21

## 2. 結論

- `data/output/8144_output.csv` の `全社` は、住所 `東京都千代田区丸の内1丁目4-5300` と土地面積 `1402.75㎡` の組み合わせが誤り。
- 2025年3月31日時点の有報「主要な設備の状況」では、`1402.75㎡` は提出会社の `本社` に対応し、所在地は `大阪市浪速区`。
- 東京の自社保有地は別行の `東京貸事務所` で、土地面積は `390.27㎡`。したがって今回の問題は合算ではなく、行取り違えによる東京過大評価。
- パッチは `全社 -> 大阪府大阪市浪速区日本橋東2丁目1番3号` とした。分割は不要。

## 3. 元データ

- 元の土地面積: 1,402.75 m2
- 元住所: 東京都千代田区丸の内1丁目4-5300
- 問題点: 東京住所と土地面積の対応が有報本文と一致しない

有報「主要な設備の状況」（2025-03-31 時点）の対応:

- 本社: 大阪市浪速区 / 土地 1,402.75㎡ / 簿価 491百万円
- 東京貸事務所: 東京都千代田区 / 土地 390.27㎡ / 簿価 247百万円

## 4. テナント誤認の確認

- 有報は所有設備と賃借設備を明確に分けている。
- 東京の賃借設備として `マクセル事業本部`（東京都台東区）などが別表で開示されており、テナント物件を所有土地として混ぜている形跡は今回の `全社` 行には見当たらない。
- 一方で公式サイトの営業拠点として、関東営業部は `東京都千代田区外神田5丁目6番7号 関東DGビル`。これは有報の `東京貸事務所 390.27㎡` と整合する東京側の自社保有拠点候補。

## 6. ジオコード確認

- `東京都千代田区外神田5丁目6番7号` は `TokyoGeocoder` で `gaiku` 解決を確認。
