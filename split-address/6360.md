# 6360 split-address 調査メモ

## 1. 結論

- 証券コード: 6360
- 企業名: 株式会社東京自働機械製作所
- 判定: 分割不要
- 対応: `本社` の住所を `東京都千代田区岩本町3丁目10番7号` に補正する

## 2. 根拠

- 2025年6月25日提出の有価証券報告書表紙で、本店所在地は `東京都千代田区岩本町3丁目10番7号東自機ビル`
- 同有報の「主要な設備の状況」では、東京の自社土地は `本社 (東京都千代田区)` の `484㎡` のみ
- 同設備表の他拠点は `柏工場 50,999㎡`、`設計開発部 1,960㎡`、`富里 31,962㎡` で、いずれも千葉県所在
- したがって、出力CSVの `本社 484㎡` は合算行ではなく、千葉県拠点が東京都本社に混入している形跡はない
- 公式サイトの会社概要・国内事業所一覧でも本社所在地は `東京都千代田区岩本町3-10-7`

## 3. 修正方針

- `東京都千代田区丸の内1丁目3番3号` は有報表紙・公式サイトと不一致
- `本社` を `東京都千代田区岩本町3丁目10番7号` に補正する
- `東京都千代田区岩本町3丁目10番7号` は東京ジオコーダで `gaiku` 解決を確認済み
