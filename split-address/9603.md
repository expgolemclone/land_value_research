# 9603 split-address 調査メモ

## 1. 対象

- 証券コード: 9603
- 企業名: 株式会社エイチ・アイ・エス
- 対象事業所: Ｈ.Ｉ.Ｓ.ホテルホールディン
- 更新日: 2026-03-17

## 2. 元データと問題点

- 出力CSV上の住所: `東京都港区港南2丁目15-1`
- 出力CSV上の土地面積: `72,000㎡`
- 有報「主要な設備の状況」: `Ｈ.Ｉ.Ｓ.ホテルホールディングス株式会社 (東京都港区他) 土地 20,006百万円 (72千㎡)`
- 問題点: ホテル事業子会社の土地 72,000㎡ を港南 1 点に寄せると、港区商業地単価で `8,191億円` まで膨らみ、都心ホテル会社として不自然。しかも有報原文が明示的に `東京都港区他` としており、単独所在地ではない。

## 3. 判定

- BAD_PATTERN_1 該当
- 判定理由:
  - 2026-01-27提出の有報では、H.I.S.ホテルホールディングス株式会社の主要設備所在地が `東京都港区他` と明記されている。
  - 2024-10-04 と 2025-07-01 の公式リリースでも、同社は `本社：東京都港区` とされつつ、東京以外を含む多数ホテルを運営している。
  - よって `東京都港区港南2丁目15-1` に 72,000㎡ 全量を置くのは誤りで、港区代表地点と全国ホテル資産の合算残へ分割するのが妥当。

## 4. 分割方針

- 港区代表地点: `東京都港区港南2丁目15-1`
- 港区代表地点の推定面積: `3,811㎡`
- 全国ホテル資産の合算残: `68,189㎡`

推定式:

```text
72,000㎡ - 3,811㎡ = 68,189㎡
```

港区代表地点の `3,811㎡` は、出力CSVで当該住所の最近傍公示点として使われている `13103-005-026` に対応する公示地価標準地 `港5-26`（東京都港区港南2丁目16番2外、地積3,811㎡）を近傍代理値として採用した。

## 6. 推論上の留保

- 期末時点の H.I.S.ホテルホールディングス株式会社の**番地レベル本店所在地**は、公式リリースでは `東京都港区` までしか確認できなかった。
- そのためパッチ上の港区代表地点 `東京都港区港南2丁目15-1` は、出力CSVで既に `gaiku` 解決されている住所を採用した。これは有報の `東京都港区他` を 1 点へ代表させるための実務上の代表地点であり、72,000㎡ 全量の所在を意味しない。

## 7. ジオコード確認

- `東京都港区港南2丁目15-1` は `gaiku`
- `全国各所` は合算残のプレースホルダであり、個別ジオコード対象外

## 8. 最終結論

- 9603 の異常値は、H.I.S.ホテルホールディングス株式会社の `東京都港区他 72,000㎡` を港区 1 点へ誤配賦していることが主因。
- パッチでは `Ｈ.Ｉ.Ｓ.ホテルホールディン` を `港区代表地点 3,811㎡` と `全国ホテル資産・合算残 68,189㎡` に分割する。
