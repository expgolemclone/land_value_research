# 9213 split-address 推論メモ

## 1. 対象

- 証券コード: 9213
- 企業名: 株式会社セイファート
- 対象事業所: 本社
- 更新日: 2026-03-19

## 2. 判定: 含み益は存在しない（誤抽出）

**この銘柄の土地含み益はゼロ。ratio=7.485は賃借設備の誤抽出が原因。**

### パイプライン出力

| 事業所名 | 土地面積(m2) | 土地簿価(円)   | 推定時価(億円) |
| -------- | ------------ | -------------- | -------------- |
| 本社     | 908.82       | 86,008,000,000 | 75             |

- 時価総額10億円に対し ratio=7.485

### 有報の実態

有報「主要な設備の状況」(1)提出会社の設備表に**土地列は存在しない**。帳簿価額の列は建物・車両運搬具・工具器具備品・ソフトウエア・ソフトウエア仮勘定・その他のみ。

有報注記3に「連結会社以外から賃借している設備」として：

| 事業所名         | 床面積(m2) | 年間賃借料(千円) |
| ---------------- | ---------- | ---------------- |
| 本社(渋谷区)     | 908.82     | 86,008           |
| 東海ブランチ     | 107.59     | 4,384            |
| 関西ブランチ     | 224.43     | 8,506            |

パイプラインが **床面積908.82m²** を土地面積、**年間賃借料86,008千円** を土地簿価86,008,000,000円（千円→円の単位変換も誤り）として取り込んだ。

### 簿価の異常値

- 「土地簿価」860億円 — 渋谷区の909m²が860億円は明らかに異常
- 推定時価75億に対し簿価860億で評価倍率0.087 — 含み損状態は通常ありえない
- 実際は年間賃借料8,601万円（渋谷の事務所賃料として妥当）
