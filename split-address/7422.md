# 7422 split-address 調査メモ

## 1. 対象

- 証券コード: 7422
- 企業名: 東邦レマック株式会社
- 更新日: 2026-04-05

## 2. 元データと問題点

- 有報「主要な設備の状況」では東京関連として `本社ビル 186.77㎡`、`社宅及び寮 63.59㎡ (東京都文京区他)`、`賃貸不動産 161.58㎡ (東京都中央区)`、`賃貸不動産 97.68㎡ (東京都文京区)`、`賃貸不動産 66.59㎡ (東京都文京区)` が記載されている。
- ただし出力CSVには `賃貸不動産 97.68㎡ (東京都文京区)` が落ちており、東京側土地を過大に1点集中させているのではなく、むしろ1件欠落している。
- 出力CSVの `本社ビル` / `賃貸不動産(文京区)` の住所 `東京都文京区湯島3-42-61` は、公式住所 `東京都文京区湯島3丁目42番6号` の誤解像と判断。

## 3. 結論

- `本社ビル` は `東京都文京区湯島3丁目42番6号` に補正可能。
- `社宅及び寮` は一次情報が `東京都文京区他` までで、番地レベルの分割根拠は見つからなかった。代表地点として `東京都文京区湯島3丁目42番6号` を採用。
- `賃貸不動産` については、文京区側は湯島3-42-6に実在する自社名ビル/賃貸募集の痕跡があり「単なるテナント誤認」とは言い難い。
- 中央区側も `八重洲2丁目10` 街区に実在する店舗・事務所ビル群と用途が整合するが、東邦レマック保有物件と外部公開情報を直接ひも付ける一次根拠までは取れなかった。
- 現行 `address_patches` は同名 `賃貸不動産` の重複行を安全に個別指定できないため、`賃貸不動産` は未パッチとした。
