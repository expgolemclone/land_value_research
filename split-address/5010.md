# 5010 split-address 調査メモ

## 1. 対象

- 証券コード: 5010
- 企業名: 日本精蝋株式会社
- 対象事業所: 本社
- 更新日: 2026-03-17

## 2. 元データ

- 元の土地面積: 2,000 m2
- 元住所: 東京都中央区京橋2丁目5番18号
- 問題意識: 中央区京橋の都心オフィス住所に対して 2,000 m2 は大きく、推定土地時価が時価総額を大幅に上回っている

## 3. 確認結果

- 有報抽出では東京側の対象は `本社` のみで、事業所名に「他」「及び」などの合算シグナルはない
- 公式サイトの会社概要でも本社所在地は `東京都中央区京橋2丁目5番18号 京橋創生館10階` とされており、CSV の番地と一致する
- 一方、京橋創生館の物件情報では敷地面積が `893.55㎡` とされており、有報の土地面積 2,000 m2 と単純には整合しない
- 有報の主要設備注記では `本社建物` を他者から賃借している記載があり、本社はオフィスビル区画の利用とみられる

## 4. 判断

- 現時点では、京橋 2-5-18 に紐づく `本社` を別住所へ分割する根拠は確認できなかった
- 過大評価の疑いはあるが、原因は住所の合算ではなく、都心ビルの敷地持分や付随土地を単純に `2,000 m2` と評価計算へ載せている点にある可能性が高い
- そのため address patch では分割せず、本社住所の確認登録に留める
