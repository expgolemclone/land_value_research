# 4095 split-address 推論メモ

## 1. 対象

- 証券コード: 4095
- 企業名: 日本パーカライジング株式会社
- 対象事業所: 加工事業
- 更新日: 2026-03-21

## 2. 元データ

- 元の土地面積: 93,000 m2
- 元住所: 東京都中央区日本橋1丁目15番1
- 問題点: 有報では国内子会社 `パーカー加工(株)` の所在地が東京都中央区だが、公式サイト上の本社は `東京都中央区日本橋3-12-1 第1三木ビル 5F` で、全国に関東・関西・東海・北陸・九州の複数工場を持つ。中央区単独 93,000 m2 は不自然。

## 4. 推論

- 東京側の実住所は `東京都中央区日本橋3丁目12番1号` と確定。
- ただし本社は `第1三木ビル 5F` の賃貸オフィス表記であり、93,000 m2 の土地全量を東京本社に紐付けるのは不適切。
- 東京側の `area_m2` は、公開されている `第1三木ビル` の基準階面積 490.90 m2 を、土地持分の上限代理値として 490.0 m2 に丸めて採用する。
- 残余 92,510.0 m2 は、公式サイトで確認できる全国工場群に属する土地の合算とみなし、`全国各所` に逃がす。

## 5. 配分式

```text
東京本社推定 = 490.0 m2
全国工場等 = 93,000.0 - 490.0 = 92,510.0 m2
```

## 6. 最終登録値

- `加工事業(日本橋本社・テナント)` : `東京都中央区日本橋3丁目12番1号`, `490.0 m2`
- `加工事業(全国工場等・合算)` : `全国各所`, `92,510.0 m2`

## 7. 補足

- `装置事業` は `パーカーエンジニアリング(株)` の本社 `東京都中央区日本橋2丁目16番8号` が親会社本社ビルと同じ `第二パーカービル` で、少面積 3,000 m2 のため分割不要。
- `薬品事業加工事業` は `日本カニゼン(株)` 本社 `東京都足立区宮城1丁目35番11号` まで gaiku 解像度で確定したが、72,000 m2 の内訳を東京と群馬・三重・千葉へ厳密配分する一次資料は不足しているため、この回では住所補正のみに留めた。
