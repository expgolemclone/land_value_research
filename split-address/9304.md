# 9304 split-address 推論メモ

- 既存出力では `本店` `広域営業部` `東京支店` の 3 件がすべて `東京都江東区永代2丁目37番28号` にジオコードされていた
- これにより、同一住所へ合計 `117,130m2` が重複して積み上がり、東京都合計 ratio が `1.674` まで膨らんでいた

## 3. 判定

- 有報の各行はすべて所在地に `ほか` を含み、単独地点ではない
- 公式事業所一覧でも、各部門の配下に複数の営業所・倉庫がぶら下がっている
- したがって、現在のパイプライン出力は `BAD_PATTERN_1` の「代表住所への合算誤投影」に該当する

## 4. 分割方針

### 本店

- 公式事業所一覧から本店住所を `東京都江東区永代2丁目37番28号` と確定
- 有報注記1で `北海道小樽市所在の土地 1,050m2` が本店所管に含まれることが明示されており、`34,650m2` 全量が永代ではない
- 永代側には `澁澤シティプレイス永代` の基準階面積 `498坪` を proxy として採用する
- `498坪 × 3.305785 = 1,646.28m2`
- 残差 `34,650 - 1,646.28 = 33,003.72m2` は `全国各所` に退避

### 広域営業部

- 公式事業所一覧では永代本部のほか、多摩営業所、三芳倉庫、京葉配送営業所、市川倉庫、船橋第二倉庫、西浦倉庫、厚木営業所など多数拠点を所管
- `57,092m2` を永代1地点へ置くのは不適切
- 永代は事務所機能とみなし `0.0m2`、全量を `全国各所` に退避

### 引越営業支店

- 公式事業所一覧で本拠住所は `東京都江戸川区北葛西4丁目11番5号`
- ただし同一覧では筑波・仙台・中部・西日本引越営業所も同組織配下にあり、有報の `東京都江戸川区ほか` と整合
- 北葛西の事務所側は `0.0m2`、全量を `全国各所` に退避

### 東京支店

- 公式事業所一覧では永代本部のほか、東京港営業所、平和島倉庫、青海倉庫、板橋営業所、松戸営業所、三郷営業所、栃木営業所などを所管
- `25,388m2` を永代1地点へ置くのは不適切
- 永代は事務所機能とみなし `0.0m2`、全量を `全国各所` に退避

## 5. 期待効果

- 現行は永代アドレスへの重複計上が主因
- 本パッチでは、永代側の東京評価対象は本店 proxy `1,646.28m2` のみに縮小
- よって東京都合計 ratio は `1.674` から大幅に低下する見込み

## 7. 判断メモ

- `広域営業部` `東京支店` `引越営業支店` の東京側面積を 0 としたのは、土地がゼロと断定したのではなく、`ほか` を含む合算面積を永代/北葛西の単一点へ載せる過大計上を止めるための保守対応
