# 1827 split-address 推論メモ

## 1. 対象

- 証券コード: 1827
- 企業名: 株式会社ナカノフドー建設
- 対象事業所: 本店・東京本店
- 更新日: 2026-03-17

## 2. 元データ

- 元の土地面積: 10,272.0 m2
- 元住所: 東京都千代田区丸の内1丁目4番5号
- 問題点: 出力CSVの丸の内1-4-5は三菱UFJ銀行本店の住所で、ナカノフドー建設の公式本店所在地ではない。有報の設備表も所在地を「東京都千代田区他」としており、単一地番評価は不適切。

## 3. 判定

- 判定: 過大評価の疑いあり
- 理由: 有報の提出会社設備は `本店・東京本店 / 東京都千代田区他 / 土地 10,272m2` で、公式サイトでは本社と東京本店が別住所として掲示されている。丸の内一点に10,272m2をぶら下げるのは住所・面積の両面で不自然。
- 対応: `本店・東京本店` を `本社(NF九段)`、`東京本店(五番町)`、`本店・東京本店(合算残余資産)` に分割する。

## 5. 推論式

- 有報の `本店・東京本店` 10,272m2 は所在地欄が「東京都千代田区他」で、公式サイト上も本社と東京本店が別住所になっているため、少なくとも2地点以上の合算と判断。
- 本社は公式会社概要と法人番号サイトがともに `東京都千代田区九段北4丁目2番28号` を示すため、この住所を採用。
- 本社地積の直接開示は見当たらないため、九段北4丁目近傍標準地の地積231m2を保守的 proxy として採用。
- 東京本店は公式会社概要が `東京都千代田区五番町4-7` を示し、同住所のグループ会社 `㈱NFエージェンシー` について有報国内子会社設備に土地793m2の開示があるため、五番町側の proxy として793m2を採用。
- 残余面積は以下の通り。
- 推定式: `10,272 - 231 - 793 = 9,248`

## 6. ジオコード確認

- `東京都千代田区九段北4丁目2番28号` は `gaiku`
- `東京都千代田区五番町4番7号` は公式住所だが、TokyoGeocoderでは `muni_centroid` 止まり
- `東京都千代田区丸の内1丁目4番5号` は `gaiku` だが、会社公式所在地と不一致のため不採用
